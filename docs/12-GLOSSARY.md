# 12 · Glossary

| Word | Meaning |
|---|---|
| **Ops** | Operations: the team and system for the client side |
| **TA** | Talent acquisition: the recruiters and the system for the candidate side |
| **TA lead** | The lead recruiter: assigns TAs to positions, sets the daily 100% |
| **Ops owner** | The one ops person who owns a client (movable by the ops lead) |
| **Lead** | A new enquiry from a possible client (not to be confused with TA lead) |
| **Intro call** | The first call with a new client; the TA lead is on every one |
| **ESA** | The client agreement Career 141 signs with each client: fee rule, guarantee, payment terms, inactivity rule |
| **Countersign** | The Director (Mr Azeem) signs the ESA after the client |
| **Requirement meeting** | The meeting where the client explains the role; no meeting, no work |
| **Opening / position / job** | One role to fill for one client. In the TA System it is one `jobs` row |
| **JD** | Job description; AI drafts it, the TA approves it |
| **Advert / job post** | Where the role is advertised: LinkedIn (mandatory), TopJobs, Talent Pulse |
| **TopJobs** | A Sri Lankan job site; takes flyers only; ad closes after 2 weeks |
| **Talent Pulse** | Career 141's weekly LinkedIn newsletter of open roles (list Tuesday, post Wednesday) |
| **100%** | A TA's full-hunt day on a position (other modes: Follow-up, Add-on) |
| **Add-on** | Extra search time (30-60 min a day) when 3 or fewer candidates are pending |
| **Follow-up** | Chasing a candidate for CV, salary and notice period (AI and TA) |
| **Director set / Director review** | A set of at least 5 CVs sent to the Director at end of day; the Director shortlists or rejects (no reason needed) |
| **EOD email** | The TA's end-of-day email to the Director desk, carrying the Director set |
| **Client set** | A set of at least 5 Director-shortlisted CVs sent to the client: "CLIENT > ROLE > SET n" |
| **Ownership window / claim** | The client has 7 working days from receipt to say they already had a CV; then the CV is dropped and marked client-owned |
| **Pipeline depth** | Counting pending and shortlisted candidates: 3 or fewer pending → add-on; 5 shortlisted → hold and monitor |
| **On hold** | Position paused (client silent, or 5 shortlisted); lifts when the client returns or the count drops |
| **Place** | The TA's button when a candidate accepts an offer: records package, joining date, offer letter |
| **DOJ** | Date of joining |
| **No-show** | The candidate does not join (or does not attend an interview) |
| **Guarantee** | 90 days from joining; if the candidate leaves, Career 141 replaces first, else refunds 25% |
| **Replacement** | A new candidate for the same position after a leaver; starts a new 90-day guarantee, no new invoice |
| **Unreported hire** | The client hires a candidate from a set without telling Career 141 within 3 months; 50% surcharge |
| **Write-off** | Fee unpaid after about 2 months; no guarantee; position closed |
| **Draft → approve → send** | The rule for client messages: the system drafts, a person approves, the system sends |
| **Outbound safety checks** | The code that stops messages reaching real people by mistake (test mode until switched live) |
| **API** | The controlled door through which Ops reads from and writes to the TA System |
| **Event** | A message TA leaves for Ops when something changes ("placement made") |
| **Staging** | A test copy of the systems on the server, used before anything goes live |
| **Canvas** | The owner's planning board ("Career 141 operations") holding all flows and notes |
| **c5237, c3626 …** | Canvas card numbers; c5237 is the newest two-system flow |
| **Convex** | The backend and database technology the TA System uses (self-hosted on the VPS) |
| **VPS** | The rented server (94.136.189.48) that runs the live TA System |
